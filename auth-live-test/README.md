# 화장수리 Firebase 독립 회원관리 테스트 (판매용 아님)

이 폴더는 기존 홈 H4, 눈썹 v18.8, 입술 앱과 별개입니다. 기존 파일을 변경하지 않았습니다.

## 진행 상태
- Firebase 이메일·비밀번호, Firestore Standard 기본 DB가 사용자의 개인 계정에 생성됐다고 사용자로부터 확인받음 (직접 서버 검증은 **미완료**).
- `index.html`: 실제 Firebase SDK를 호출하는 시험 UI. Firebase Web App 구성 객체가 연결되어야 동작.
- `firestore.rules`: **실험용 규칙 초안**. GitHub에 업로드한 것만으로 Firebase에 배포되지는 않음. 테스트 프로젝트에서 사전 검토 후 별도 적용해야 함.
- 로그인, 가상 구매, 기기 1대 등록, 타 기기로 이전, 이전 기기 재확인까지 설계.
- 실제 결제 확인·실제 비용 0원·서버 규칙 통합 테스트는 **검증되지 않음**.

## 보안 경고
`labSeats`에서 사용자가 누르는 '가상 구매'는 **실제 결제가 아닌 시험 상태**입니다. 실판매에는 절대 연결하지 마세요. 실제 `licenses`는 클라이언트에서 쓰기 불가로 설계했고, 신뢰할 수 있는 서버에서 결제 검증 후 지급해야 합니다.

기기 이전 후 이전 기기가 **서버에 다시 조회하기 전에는** 이미 다운로드한 웹 편집 코드를 사용할 수도 있습니다. 사용 권한·기기 제한을 확실히 구현하려면 보호 대상 기능의 서버 측 검증 구조도 따로 검토해야 합니다. Firebase 무료 이용 범위를 넘으면 기능이 제한될 수 있고, 규칙의 get()/exists()도 읽기에 포함될 수 있습니다.

## 라이브 테스트에 추가로 필요한 사항
1. Firebase 콘솔에서 테스트 프로젝트 웹앱 등록 및 웹 구성 객체 확인.
2. 필요한 경우 승인된 인증 도메인 등록.
3. **테스트 프로젝트에만** 규칙을 적용하고 에뮬레이터/Rules Playground에서 보안 점검.
4. 테스트용 계정 2기기 시나리오 수행. Firebase 사용량 탭에서 실제 읽기/쓰기 확인.

고객 사진·진짜 고객 정보는 시험 데이터베이스에 넣지 않습니다. 서비스 계정 비밀키는 화면에 입력하지 않습니다.

공식 문서: https://firebase.google.com/docs/firestore/security/get-started , https://firebase.google.com/docs/firestore/quotas
